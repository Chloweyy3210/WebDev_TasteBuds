# Taste Buds Catering — Website

A directory-style website connecting event hosts in South Africa with independent local caterers and food trucks. Built as part of the WEDE5020 Portfolio of Evidence.

## About the project

Taste Buds Catering is a Johannesburg-founded platform where hosts can browse vetted local vendors, compare menus and prices, and send direct enquiries — and where independent caterers and food trucks can get discovered without needing their own website or marketing budget.

## Technologies used

- HTML5
- CSS3
- Vanilla JavaScript (navigation toggle, tabbed enquiry forms, form handling)
- Git & GitHub for version control
